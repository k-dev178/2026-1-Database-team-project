# 요구사항 분석 수정

## 차량 관리

| # | 요구사항 |
| - | -------------------------------------------------------------- |
| 1 | 판매 담당자는 **차량 상태 정보**를 기록해야 한다. 차량 상태는 입고, 정비중, 판매중 중 하나로 관리한다. |
| 2 | 판매 담당자와 고객은 **차량 정보**를 차량번호, 모델명, 연식으로 검색해야 한다. |
| 3 | 시스템은 **차량 상태 정보**를 **판매 완료 차량 정보**와 **현재 재고 차량 정보**와 구분하여 저장해야 한다. |
| 4 | 매입 담당자는 **차량 가격 정보**에 차량의 매입가와 판매가를 기록해야 한다. |
| 5 | 판매 담당자는 **차량 비용 정보**에 정비비, 세차비, 탁송비 등의 추가 비용을 기록해야 한다. |
| 6 | 판매 담당자는 **차량 담당자 정보**를 지정하고 기록해야 한다. |
| 7 | 시스템은 **차량 등록 정보**에 매물 등록일과 판매일을 자동으로 기록해야 한다. |

## 판매 관리

| # | 요구사항 |
| - | ---------------------------------------------------- |
| 1 | 시스템은 **판매계약 정보**와 **차량 인도 정보**를 저장한다. |
| 2 | 판매 담당자는 **판매방식 정보**에 현금, 할부, 금융 연계 여부를 구분하여 기록해야 한다. |
| 3 | 판매 담당자는 **차량 인도 정보**에 차량 인도 완료 여부를 기록해야 한다.     |
| 4 | 판매 담당자는 **판매계약 정보**와 **차량 인도 정보**를 조회해야 한다. |


## 고객 관리

| # | 요구사항                                                       |
| - | ---------------------------------------------------------- |
| 1 | 구매자는 **고객 정보**를 이름 연락처 주소등을 등록한다.          |
| 2 | 판매 담당자는 **고객 정보**중 이름과 연락처를 주소를 조회한다. |
| 3 | 판매 담당자는 **고객 관심차량 정보**와 **방문이력 정보**를 등록하고 조회해야 한다. |
| 4 | 시스템은 **구매예약 정보**의 예약 상태를 관리하여 동일 차량에 구매예약이 중복되지 않도록 해야 한다. |


## 정비 / 상품화

| # | 요구사항                                                   |
| - | ------------------------------------------------------ |
| 1 | 차량관리사는 **점검기록 정보**에 차량별 주행거리와 주요 점검 결과를 저장해야 한다.       |
| 2 | 차량관리사는 **성능점검기록 정보**에 성능 점검 기록과 검사 결과를 차량별로 저장해야 한다.   |
| 3 | 차량관리사는 **정비항목 정보**를 등록하고 진행 상태를 기록해야 한다.               |
| 4 | 차량관리사는 **상품화작업 정보**에 세차, 광택, 소모품 교체 등의 작업 내역을 기록해야 한다. |


## 사후 관리

| # | 요구사항                                               |
| - | -------------------------------------------------- |
| 1 | 판매 담당자는 **보증 정보**에 판매 후 차량의 보증 기간과 보증 항목을 기록해야 한다. |
| 2 | 고객은 **A/S 요청 정보**에 차량 구매 후 문의나 A/S 요청을 등록해야 한다.    |
| 3 | 사후관리담당자는 **사후처리이력 정보**를 저장하고 조회해야 한다.               |
| 4 | 사후관리담당자는 **클레임 정보**에 고객 불만과 처리 상태를 기록하고 관리해야 한다.       |
