# 11주차 과제: 개체 타입 통합

## 1. 통합 기준

- 기본키가 같거나 비슷하면 합친다.
- 속성이 비슷하면 합친다.
- 합친 뒤에는 `역할`, `유형`, `상태` 같은 칸으로 구분한다.

---

## 2. 통합한 것

### 직원

판매 담당, 차량 관리 담당, 사후처리 담당은 모두 직원이다.

그래서 직원 하나로 합치고 `역할`로 구분한다.

```
직원(직원번호, 이름, 연락처, 역할)
```

### 판매계약

예약도 판매계약과 관련이 있으므로 판매계약 안에 넣는다.

```
판매계약(계약번호, 계약일, 계약금액, 판매방식, 인도완료여부, 인도일, 예약일, 예약상태, 차량식별번호, 고객번호, 직원번호)
```

### 사후처리

보증 처리 같은 것도 사후처리 안에 넣는다.

처리 종류는 `처리유형`으로 구분한다.

```
사후처리(처리번호, 처리유형, 요청일, 처리일, 처리내용, 처리상태, 보증기간, 보증항목, 차량식별번호, 고객번호)
```

---

## 3. 그대로 둔 것

고객, 차량은 뜻이 달라서 합치지 않는다.

`관리하다`, `처리하다`는 여러 개가 서로 연결되므로 따로 둔다.

```
관리하다(직원번호, 차량식별번호)
처리하다(직원번호, 처리번호)
```
