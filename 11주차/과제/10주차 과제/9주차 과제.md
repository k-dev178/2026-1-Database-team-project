# 관계 데이터 모델

ER 다이어그램을 바탕으로 데이터를 2차원 표 형태의 릴레이션으로 표현하였다.

---

## 1. 고객 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 고객번호 | int | PK | 고객을 구분하는 기본키 |
| 이름 | varchar(50) | NOT NULL | 고객 이름 |

---

## 2. 고객주소 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 주소번호 | int | PK | 주소를 구분하는 기본키 |
| 고객번호 | int | FK, NOT NULL | 고객(고객번호)을 참조 |
| 시도 | varchar(30) | NOT NULL | 시/도 |
| 시군구 | varchar(30) | NOT NULL | 시/군/구 |
| 상세주소 | varchar(100) |  | 상세 주소 |

---

## 3. 고객연락처 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 연락처번호 | int | PK | 연락처를 구분하는 기본키 |
| 고객번호 | int | FK, NOT NULL | 고객(고객번호)을 참조 |
| 연락처 | varchar(20) | NOT NULL | 고객 연락처 |
| 연락처종류 | varchar(20) |  | 휴대폰, 집전화 등 연락처 종류 |

---

## 4. 직원 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 직원번호 | int | PK | 직원을 구분하는 기본키 |
| 이름 | varchar(50) | NOT NULL | 직원 이름 |
| 기본연락처 | varchar(20) | NOT NULL | 직원 기본 연락처 |
| 역할 | 직원역할 | NOT NULL | 직원 역할 |

---

## 5. 판매직원 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 직원번호 | int | PK, FK | 직원(직원번호)을 참조 |
| 판매등급 | varchar(30) |  | 판매 직원 등급 |
| 인센티브율 | decimal(5,2) |  | 판매 인센티브율 |

---

## 6. 정비직원 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 직원번호 | int | PK, FK | 직원(직원번호)을 참조 |
| 전문분야 | varchar(50) |  | 정비 전문 분야 |
| 자격증여부 | varchar(10) |  | 자격증 보유 여부 |

---

## 7. 차량 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 차량번호 | int | PK | 차량을 구분하는 기본키 |
| 모델명 | varchar(50) | NOT NULL | 차량 모델명 |
| 연식 | int | NOT NULL | 차량 연식 |
| 주행거리 | int | NOT NULL | 차량 주행거리 |
| 차량상태 | 차량상태 | NOT NULL | 차량 상태 |
| 매입가 | int |  | 차량 매입 가격 |
| 판매가 | int |  | 차량 판매 가격 |
| 입고일 | date | NOT NULL | 차량 입고일 |

---

## 8. 판매 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 판매번호 | int | PK | 판매 내역을 구분하는 기본키 |
| 판매일자 | date | NOT NULL | 차량 판매일 |
| 판매방식 | 판매방식 | NOT NULL | 판매 방식 |
| 판매금액 | int | NOT NULL | 판매 금액 |
| 고객번호 | int | FK, NOT NULL | 고객(고객번호)을 참조 |
| 직원번호 | int | FK, NOT NULL | 판매직원(직원번호)을 참조 |
| 차량번호 | int | FK, NOT NULL | 차량(차량번호)을 참조 |

---

## 9. 정비 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 정비번호 | int | PK | 정비 내역을 구분하는 기본키 |
| 정비일자 | date | NOT NULL | 정비한 날짜 |
| 정비내용 | varchar(100) | NOT NULL | 정비 내용 |
| 정비비용 | int | NOT NULL | 정비 비용 |
| 정비상태 | 정비상태 | NOT NULL | 정비 진행 상태 |
| 직원번호 | int | FK, NOT NULL | 정비직원(직원번호)을 참조 |
| 차량번호 | int | FK, NOT NULL | 차량(차량번호)을 참조 |

---

## 10. 부품 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 부품번호 | int | PK | 부품을 구분하는 기본키 |
| 부품명 | varchar(50) | NOT NULL | 부품 이름 |
| 단가 | int | NOT NULL | 부품 단가 |

---

## 11. 정비부품 릴레이션

| 속성명 | 자료형 | 제약조건 | 설명 |
|---|---:|---|---|
| 정비번호 | int | PK, FK, NOT NULL | 정비(정비번호)를 참조 |
| 부품번호 | int | PK, FK, NOT NULL | 부품(부품번호)을 참조 |
| 수량 | int | NOT NULL | 사용한 부품 수량 |
| 사용금액 | int |  | 부품 사용 금액 |

---

# 릴레이션 스키마 요약

| 릴레이션명 | 릴레이션 스키마 |
|---|---|
| 고객 | 고객(**고객번호**, 이름) |
| 고객주소 | 고객주소(**주소번호**, 고객번호, 시도, 시군구, 상세주소) |
| 고객연락처 | 고객연락처(**연락처번호**, 고객번호, 연락처, 연락처종류) |
| 직원 | 직원(**직원번호**, 이름, 기본연락처, 역할) |
| 판매직원 | 판매직원(**직원번호**, 판매등급, 인센티브율) |
| 정비직원 | 정비직원(**직원번호**, 전문분야, 자격증여부) |
| 차량 | 차량(**차량번호**, 모델명, 연식, 주행거리, 차량상태, 매입가, 판매가, 입고일) |
| 판매 | 판매(**판매번호**, 판매일자, 판매방식, 판매금액, 고객번호, 직원번호, 차량번호) |
| 정비 | 정비(**정비번호**, 정비일자, 정비내용, 정비비용, 정비상태, 직원번호, 차량번호) |
| 부품 | 부품(**부품번호**, 부품명, 단가) |
| 정비부품 | 정비부품(**정비번호**, **부품번호**, 수량, 사용금액) |

---

# 기본키 및 외래키 요약

| 릴레이션명 | 기본키(PK) | 외래키(FK) |
|---|---|---|
| 고객 | 고객번호 | - |
| 고객주소 | 주소번호 | 고객번호 → 고객(고객번호) |
| 고객연락처 | 연락처번호 | 고객번호 → 고객(고객번호) |
| 직원 | 직원번호 | - |
| 판매직원 | 직원번호 | 직원번호 → 직원(직원번호) |
| 정비직원 | 직원번호 | 직원번호 → 직원(직원번호) |
| 차량 | 차량번호 | - |
| 판매 | 판매번호 | 고객번호 → 고객(고객번호)<br>직원번호 → 판매직원(직원번호)<br>차량번호 → 차량(차량번호) |
| 정비 | 정비번호 | 직원번호 → 정비직원(직원번호)<br>차량번호 → 차량(차량번호) |
| 부품 | 부품번호 | - |
| 정비부품 | 정비번호, 부품번호 | 정비번호 → 정비(정비번호)<br>부품번호 → 부품(부품번호) |
