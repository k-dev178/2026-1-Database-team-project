# 데이터가 속한 세계와 데이터의 특징
예) 얼굴이 둥근형이고 머리가 검은색인 김동우, 얼굴은 달걀형이고 머리가 갈색인 이영미, 얼굴은 사각형이고 머리가 노란색인 박종민.

- 현실세계: 얼굴이 둥근형이고 머리가 검은색인 김동우, 얼굴은 달걀형이고 머리가 갈색인 이영미, 얼굴은 사각형이고 머리가 노란색인 박종민.
- 개념 세계: 얼굴형, 머리색, 이름 속성을 갖는 학생이라는 '개체' 타입.
- 컴퓨터 세계: face, hair, name 이라는 필드를 갖는 'student'라는 레코드 타입.

즉 현실세계는 개체(실체)로 개념 세계는 개체 타입(개념), 컴퓨터 세계는 레코드 타입(데이터)으로 표현.

# 데이터 모델링 개요
데이터 모델링이란 현실세계의 개념을 DB로 저장할 수 있는 형태로 바꾸는 과정을 말함.

즉 개념적 구조 -> 논리적 구조 -> 물리적 구조(디스크에 저장할 수 있는 형태) 순으로 변환함.

# 데이터 모델의 구성
1. (데이터) 구조
2. 연산
3. 제약조건

# 데이터 모델
## 개념적 데이터 모델
개념적 모델링을 통해 얻을 수 있는 추상화된 데이터 구조.

속성들로 구성된 '개체타입'과, '관계'로 구성됨.

## 논리적 데이터 모델
논리적 모델링을 통해 얻을 수 있는 데이터 구조. 개념적 데이터 모델보다 덜 추상적.

"레코드 타입"과 "관계"로 구성됨.
