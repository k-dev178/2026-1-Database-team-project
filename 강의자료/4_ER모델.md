# ER 모델 기본 요소
- 개체: DB가 표현하려고 하는 유*무형의 정보 대상으로서, 현실 세계에 존재하면서 서로 구별할 수 있는 요소다.
- 관계: 개체간의 의미 있는 연결 또는 연관성을 표현하는 요소다.
- 속성: 개체나 관계의 특성을 나타내는 요소로서, 이름을 가진 정보의 가장 작은 논리적 단위다.

# 개체 관련 주요 개념
## 개체 타입
'개체의 이름'과 '개체를 구성하는 속성'들을 정의한 것이다.

ex) 사원(사번, 이름, 입사일, 전공)

## 개체 인스턴스
개체의 '속성들이 구체적인 값을 가짐'으로써 실체화된 것. (개체 출현이라고도 부름.)

ex) (241013, '김희망', 20240901, '컴퓨터공학')

## 개체 집합
동일한 속성들을 가진 '개체 인스턴스들의 집합'을 의미한다.

ex) (241013, '김희망', 20240901, '컴퓨터공학'), (241020, '김소망', 20240115, '기계공학')

## 속성
개체의 특성을 나타내는 기본 요소.

즉 개체 타입 = 개체 + 속성

# 속성
개체나 관계의 특성을 나타내는 기본 요소.

## 상수 속성과 시변 속성
- 상수속성: 시간이 지나도 값이 변하지 않는 속성을 의미한다.
- 시변 속성: 고객의 주소나 휴대폰 속성처럼 시간이 지남에 따라 값이 변할 수 있는 속성을 의미한다.

## 단순 속성과 복합 속성

![alt text](<기본 폴더 - 11.jpg>)

- 단순속성: 회원번호, 이름, 휴대폰
- 복합속성: 주소

## 단일치 속성과 다중치 속성
- 단일치 속성: 특정 개체에 대해 단 하나의 값만 갖는 속성이다.
- 다중치 속성: 특정 개체에 대해 여러개의 값을 가질 수 있는 속성이다.

예)<br>
주민등록번호나 학번은 하나만 가짐.<br>
하지만 취미나 자격증은 여러개 가질 수 있음.

## 유도속성과 저장속성
- 유도속성: 다른 속성 값으로 계산(유도)해서 결정되는 속성.
- 저장속성: DB에 값이 직접 저장되는 속성.

예)
- 나이 ← 생년월일로부터 계산
- 근무년수 ← 입사일로부터 계산
- 총액 ← 단가 × 수량
- 평균 학점 ← 여러 과목 학점 평균


## 널 속성
널 값을 갖는 속성을 별도로 구분하여 널 속성이라고 부른다.

ex) 여학생의 경우 군필여부, 값이 누락, 값의 존재 여부 모름.

## 기본키 속성과 부분키 속성.
- 기본키: 각 개체 인스턴스들을 유일하게 식별할 수 있는 속성 또는 속성들의 집합.
- 부분키: 속성이란 개체를 식별할 수 있는 키를 형성하기에는 충분한 속성을 갖지 못한 약한 개체 타입의 부분적인 식별자.

# 관계 유형
## 일대일(1:1) 유형
개체 인스턴스 하나가 다른 개체 인스턴스 하나와만 연관성이 있는 유형이다.

ex) 학생 1명이 노트북 1대를 대여하는 경우.

## 일대다(1:n) 또는 다대일(n:1) 유형
두 개체 가운데 어느 한 개체를 기준으로 보면 하나 이상의 개체 인스턴스와 연관성이 있고, 다른 개체를 기준으로 보면 한 개체 인스턴스와만 연관성이 있는 유형이다.

ex) 교수 1명이 학생 여러명을 지도.

## 다대다(m:n) 유형
두 개체 가운데 어느 개체를 기준으로 보더라도 하나 이상의 개체와 연관성이 있는 유형.

ex) 학생 1명이 여러 교과목을 수강하고 교과목 1개를 여러 학생이 수강하는 경우.
