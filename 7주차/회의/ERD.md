# ERD (피터첸 표기법용 — ERDPlus 입력 가이드)

## 사용법

1. https://erdplus.com 접속 → "Create new" → **"ER Diagram"** 선택
2. 상단 툴바에서 도형 추가:
    - `Entity` (사각형) → 개체 배치
    - `Attribute` (타원) → 속성 배치 후 개체와 연결
    - `Relationship` (마름모) → 관계 배치 후 양쪽 개체와 연결
3. 속성 더블클릭 → PK는 밑줄, 다중값/유도속성 등 옵션 설정
4. 관계 연결선 더블클릭 → 카디널리티(1, N, M) 입력

---

## 1. 개체 (8개)

> PK: 기본키(밑줄 처리)
> FK: 외래키 (다른 개체 참조)

### 직원
- **직원번호** (PK, int)
- 이름 (varchar)
- 연락처 (varchar)
- 역할 (enum: 판매 / 구매 / 정비 / 애프터서비스)

### 고객
- **고객번호** (PK, int)
- 이름 (varchar)
- 주민번호 (varchar, unique)
- 연락처 (varchar)
- 주소 (varchar)

### 차량
- **차량번호** (PK, varchar)
- 모델명 (varchar)
- 연식 (int)
- 차량상태 (enum: 입고 / 정비중 / 판매중 / 판매완료)
- 매입가 (decimal)
- 판매가 (decimal)
- 매물등록일 (date)
- 판매일 (date)
- 담당직원번호 (FK → 직원)

### 판매계약
- **계약번호** (PK, int)
- 계약일 (date)
- 계약금액 (decimal)
- 판매방식 (enum: 현금 / 할부(캐피탈) / 카드)
- 인도완료여부 (boolean)
- 인도일 (date)
- 차량번호 (FK → 차량, unique)
- 고객번호 (FK → 고객)
- 직원번호 (FK → 직원)

### 구매예약
- **예약번호** (PK, int)
- 예약일 (date)
- 예약상태 (enum: 대기 / 확정 / 취소 / 완료)
- 차량번호 (FK → 차량)
- 고객번호 (FK → 고객)

### 정비항목
- **정비항목번호** (PK, int)
- 항목명 (varchar)
- 진행상태 (enum: 등록 / 진행중 / 완료)
- 차량번호 (FK → 차량)
- 직원번호 (FK → 직원)

### 상품화작업
- **작업번호** (PK, int)
- 작업명 (varchar)
- 작업일 (date)
- 정비비 (decimal)
- 세차비 (decimal)
- 탁송비 (decimal)
- 차량번호 (FK → 차량)
- 직원번호 (FK → 직원)

### 사후처리
- **처리번호** (PK, int)
- 처리유형 (enum: 보증 / 요청 / 클레임)
- 요청일 (date)
- 처리일 (date)
- 처리내용 (text)
- 처리상태 (varchar)
- 보증기간 (varchar)
- 보증항목 (varchar)
- 차량번호 (FK → 차량)
- 고객번호 (FK → 고객)
- 직원번호 (FK → 직원)

## 3. 배치 팁

### 중앙 배치 권장 개체
- **차량** — 가장 많은 관계(7개)를 맺으므로 다이어그램 중앙에 두고 주변에 연결

### 배치 예시 (시계 방향, 차량 중심)
```
          [직원]
             |
[고객] — [차량] — [판매계약]
             |
     [정비항목] [상품화작업]
             |
         [사후처리]
         [구매예약]
```

### 관계선 카디널리티 표기
- ERDPlus에서는 관계선 양 끝의 레이블에 `1`, `N`, `M` 입력
- 1:1 → 양쪽 `1`
- 1:N → 한쪽 `1`, 한쪽 `N`
- M:N → 한쪽 `M`, 한쪽 `N`
