# 중고차 판매 관리 데이터베이스

중고차 매장의 차량, 고객, 판매계약, 정비 및 사후관리 정보를 관리하기 위한 데이터베이스 설계 프로젝트입니다.

## 주요 작업

- 업무 요구사항 수집 및 분석
- ERD 작성과 개체·관계 설계
- 논리적 스키마 설계 및 정규화 검토
- 9개 테이블과 기본키·외래키·제약조건 구현
- 샘플 데이터 작성 및 SQL 삽입·수정·삭제·조회
- 조인, 집계 함수, 서브쿼리를 활용한 데이터 조회
