# 요구사항 분석 수정

## 차량 관리

| # | 요구사항 |
|---|---------|
| 1 | 판매자가 차를 지금 입고 상태인지, 정비 중인지, 판매 중인지 상태를 기록할 수 있어야 해요. |
| 2 | 차량 번호, 모델명, 연식 같은 걸로 검색해서 원하는 차를 바로 찾을 수 있어야 해요. |
| 3 | 판매가 끝난 차량은 현재 재고와 구분해서 저장할 수 있어야 해요. |
| 4 | 이 차를 얼마에 매입했고 얼마에 팔았는지 기록할 수 있어야 해요. |
| 5 | 정비비나 세차비, 탁송비 같은 추가 비용도 같이 기록할 수 있어야 해요. |
| 6 | 차량마다 담당자가 누구인지 기록할 수 있어야 해요. |
| 7 | 매물이 등록된 날짜랑 판매된 날짜를 기록할 수 있어야 해요. |

## 판매 관리

| # | 요구사항 |
|---|---------|
| 1 | 판매 완료된 차량의 계약 정보나 거래 내역을 저장하고 조회할 수 있어야 해요. |
| 2 | 판매 방식이 현금, 할부, 금융 연계인지 구분해서 기록할 수 있어야 해요. |
| 3 | 차량 인도 완료 여부를 기록할 수 있어야 해요. |

## 고객 관리

| # | 요구사항 |
|---|---------|
| 1 | 고객의 이름, 연락처, 관심 차량, 방문 이력 등을 등록하고 기록 및 조회할 수 있어야 해요. |
| 2 | 같은 차량에 여러 구매예약이 겹치지 않도록 구매예약 상태를 저장할 수 있어야 해요. |
| 3 | 판매자는 고객정보를 조회할 수 있다. |

## 정비 / 상품화

| # | 요구사항 |
|---|---------|
| 1 | 차량별 주행거리와 주요 점검 결과를 함께 저장할 수 있어야 해요. |
| 2 | 성능점검 기록이나 검사 결과를 차량별로 저장할 수 있어야 해요. |
| 3 | 매입 후 필요한 정비 항목을 등록하고 진행 상태를 저장할 수 있어야 해요. |
| 4 | 세차, 광택, 소모품 교체 같은 상품화 작업 내역도 기록할 수 있어야 해요. |

## 사후 관리

| # | 요구사항 |
|---|---------|
| 1 | 판매 후 보증 기간이나 보증 항목을 기록할 수 있어야 해요. |
| 2 | 판매 후 고객 문의나 AS 요청 내역을 저장할 수 있어야 해요. |
| 3 | 차량별 사후 처리 이력을 저장하고 조회할 수 있어야 해요. |
| 4 | 고객 불만이나 클레임 처리 상태를 기록할 수 있어야 해요. |
