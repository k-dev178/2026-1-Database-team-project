# 14주차 Exercise Sheet

## 1. 13주차까지 진행된 내용으로 데이터베이스를 구축한다.

13주차까지 진행한 중고차 매매 시스템의 논리적 설계와 물리적 설계를 바탕으로 데이터베이스를 구축하였다. 구축 대상은 직원, 고객, 차량, 차량작업, 관리하다, 판매계약, 사후처리, 처리하다, 사후처리보증항목 테이블이다.

데이터베이스 구축 과정은 다음과 같이 진행하였다.

1. 13주차 물리적 설계에서 정의한 내부 스키마를 기준으로 각 릴레이션의 컬럼명, 데이터 타입, 크기, NULL 허용 여부를 정리하였다.
2. 각 테이블의 기본키, 유일키, 외래키, CHECK 제약조건을 반영하여 `CREATE TABLE` 문을 작성하였다.
3. 외래키 참조 순서를 고려하여 직원, 고객, 차량, 차량작업, 관리하다, 판매계약, 사후처리, 처리하다, 사후처리보증항목 순서로 테이블을 생성하였다.
4. 테스트를 위해 각 테이블에 초기 데이터를 삽입하였다.
5. 자주 조회되는 차량 상태별 목록, 고객별 계약 이력, 사후처리 상태별 목록을 효율적으로 검색하기 위해 결합 인덱스를 생성하였다.

생성한 주요 테이블은 다음과 같다.

| 구분 | 테이블명 | 주요 내용 |
|---|---|---|
| 1 | 직원 | 직원번호, 이름, 연락처, 역할 관리 |
| 2 | 고객 | 고객번호, 이름, 주민번호, 연락처, 주소 관리 |
| 3 | 차량 | 차량식별번호, 차량번호, 모델명, 연식, 판매상태, 가격 정보 관리 |
| 4 | 차량작업 | 차량별 점검, 정비, 세차, 광택 등 작업 정보 관리 |
| 5 | 판매계약 | 차량 판매 계약, 결제 방식, 인도 여부, 예약 상태 관리 |
| 6 | 사후처리 | 보증, A/S, 클레임 등 판매 후 처리 정보 관리 |
| 7 | 관리하다 | 직원과 차량 사이의 관리 관계 관리 |
| 8 | 처리하다 | 직원과 사후처리 사이의 처리 관계 관리 |
| 9 | 사후처리보증항목 | 사후처리별 보증 항목 관리 |

생성한 인덱스는 다음과 같다.

```sql
CREATE INDEX IDX_차량_상태_등록일
ON 차량(vehicle_status ASC, listing_date DESC);

CREATE INDEX IDX_판매계약_고객_계약일
ON 판매계약(customer_id ASC, contract_date DESC);

CREATE INDEX IDX_사후처리_상태_요청일
ON 사후처리(service_status ASC, request_date ASC);
```

따라서 13주차까지 설계한 릴레이션, 제약조건, 초기 데이터, 인덱스를 SQL로 구현하여 데이터베이스 구축을 완료하였다.
