## 테이블

테이블 종류

- 기본 테이블: 독자적으로 존재하는 테이블
- 가상 테이블: `CREATE VIEW`로 기본 테이블에서 만든 테이블
- 임시 테이블: 질의 처리 중간 결과로 만들어지는 테이블

기본 테이블 명령

- 생성: `CREATE TABLE`
- 삭제: `DROP TABLE`
- 변경: `ALTER TABLE`

`CREATE TABLE`은 테이블 생성 권한이 있는 사용자만 사용할 수 있다.

기본키를 다른 테이블이 참조하면, 기본키와 외래키를 함께 삭제하도록 바꾼 뒤 테이블을 삭제할 수 있다.

`ALTER TABLE`로 할 수 있는 일

- 새 열 추가: `ADD`
- 기존 열 삭제: `DROP`
- 데이터 타입이나 디폴트 값 변경: `MODIFY`
- 제약조건 추가: `ADD CONSTRAINT`
- 제약조건 삭제: `DROP CONSTRAINT`

## 인덱스

- 생성: `CREATE INDEX`
- 삭제: `DROP INDEX`

인덱스 삭제 조건

- 인덱스 소유자
- `DROP ANY INDEX` 권한이 있는 사용자

인덱스는 수정하지 않는다. 수정이 필요하면 삭제 후 다시 만든다.

## 데이터 삽입

초기 데이터 삽입 명령은 `INSERT`이다.

- `VALUES` 절에 열 값을 쓴다.
- 열 이름을 쓰지 않으면 테이블에 정의된 열 순서대로 값을 써야 한다.

## 데이터 검색

검색 명령은 `SELECT`이다.

검색 방법

- 모든 열 검색
- 조건을 만족하는 행 검색
- 조건을 만족하는 특정 열 검색
- 중복 행 제거
- 행 정렬
- `GROUP BY` 사용
- `HAVING` 사용

## 데이터 삽입, 삭제, 갱신

삽입

- 직접 삽입: 빈 테이블에 초기 데이터를 넣는 방법과 같다.
- 복사 삽입: 서브쿼리 `SELECT` 결과를 복사해서 넣는다.

삭제

- `DELETE` 사용

갱신

- `UPDATE` 사용
- 1개 데이터 갱신
- 여러 개 데이터 갱신

## 뷰

뷰 생성 명령은 `CREATE VIEW`이다.

뷰가 생성되면 뷰 이름과 뷰 정의가 데이터 사전의 `USER_VIEWS` 테이블에 저장된다.

뷰 생성 예

- 단순 뷰
- 열 별칭을 사용한 단순 뷰
- 복합 뷰

뷰 삭제 명령은 `DROP VIEW`이다.

뷰에서 삽입, 삭제, 갱신이 되는 경우

- 하나의 기본 테이블에 속한 행과 열의 부분집합으로 정의된 경우

뷰에서 삽입, 삭제, 갱신이 안 되는 경우

- 상수, 산술 연산자, 함수가 사용된 산술식으로 열을 만든 경우
- `COUNT`, `SUM`, `AVG`, `MAX`, `MIN` 같은 그룹 함수를 사용한 경우
- `DISTINCT`, `GROUP BY`, `HAVING`을 사용한 경우
- 2개 이상 테이블로 뷰를 만든 경우

## 시퀀스

시퀀스는 `CREATE SEQUENCE`로 만든다.

특징

- 시퀀스 값을 미리 만들어 메모리에 저장해 사용할 수 있다.

의사열

- `NEXTVAL`: 다음 시퀀스 값을 만든다.
- `CURRVAL`: 가장 최근에 만든 현재 시퀀스 값을 반환한다.

주의

- `CURRVAL`을 쓰기 전에 반드시 `NEXTVAL`을 먼저 써야 한다.

의사열 사용 가능

- 서브쿼리가 아닌 `SELECT` 문의 `SELECT` 절
- `INSERT` 문에서 서브쿼리의 `SELECT` 절
- `INSERT` 문의 `VALUES` 절
- `UPDATE` 문의 `SET` 절

의사열 사용 불가

- 뷰의 `SELECT` 절
- `DISTINCT`를 사용한 `SELECT` 문
- `GROUP BY`, `HAVING`, `ORDER BY`를 사용한 `SELECT` 문
- `SELECT`, `DELETE`, `UPDATE` 문의 서브쿼리
- `CREATE TABLE`, `ALTER TABLE` 문의 `DEFAULT` 표현식

시퀀스 유의 사항

- 시퀀스를 포함한 문장을 롤백하면 시퀀스 번호에 간격이 생긴다.
- `CACHE` 옵션 사용 중 시스템이 비정상 종료되면 시퀀스 번호에 간격이 생긴다.
- 시퀀스 값은 불규칙적으로 변할 수 있다.

용어

- 롤백: 미결정된 데이터 변경을 취소하는 것
- 커밋: 미결정된 데이터 조작을 영구적으로 변경하는 것

시퀀스 변경

- 명령: `ALTER SEQUENCE`
- 증가치, 최댓값, 최솟값, 사이클 여부, 캐시 옵션 등을 바꿀 수 있다.
- `START WITH` 옵션은 제외된다.

변경 시 주의

- 시퀀스 생성자나 `ALTER SEQUENCE` 권한이 있는 사용자만 수정할 수 있다.
- 수정 이후 생성되는 번호에만 영향을 준다.
- 다른 시작 번호로 다시 만들려면 기존 시퀀스를 삭제하고 다시 만들어야 한다.
- 유효성 검사를 자동으로 수행한다.
- 수정한 `MAXVALUE`가 현재 시퀀스 번호보다 작으면 허용되지 않는다.

시퀀스 삭제

- 명령: `DROP SEQUENCE`
- 한 번 제거된 시퀀스는 더 이상 참조할 수 없다.
