# 데이터 모델링 개요

## 개념적 모델링
\- **현실세계를 DB로 만들기 위해 추상화하여 개념적구조로 표현하는 과정.**
\- 개념적 스키마 모델링, 정보 모델링이라고도 부른다.

> 추상화:
> 특징을 찾아서 간단하게 표현하는 것.

### 개념적 모델링 방법
\- 일반적으로 `개체 타입`과 `관계`라는 추상적 개념으로 모델링한다.
\- 주로 ER모델을 사용.
\- 모델링 결과는 ERD를 사용.

## 논리적 모델링
\- 개념정 모델링 결과인 개념적 구조를 DBMS가 이해할 수 있는 데이터 구조로 변환하는 과정.
\- 논리적 스키마 모델링이라고도 부름.
\- 논리적 모델링 방법은 데이터 모델의 종류에 따라 달라짐.(8장 참고)

## 물리적 모델링
\- 실제 디스크에 들어갈 수 있도록 논리적 구조를 물리적 구조로 변환하는 과정.
\- 물리적 스키마 모델링, 데이터 구조화라고도 불림.

### 물리적 모델링 방법
\- 저장 레코드 양식을 정의, 인덱스 설계.
