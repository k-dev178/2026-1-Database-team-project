## 데이터의 정의
데이터:
가공되지 않은 값,사실.

정보:
의사 결정을 위한 '가공된' 데이터.

방대한 양의 데이터를 더욱 효율적으로 관리하고 활용하기 위해 데이터베이스라는 개념이 출현.

## 데이터베이스의 정의

Shared data : 
데이터베이스는 한 조직 내에서 여러 응용프로그램이 공동으로 사용하는 데이터.

Integrated data:
데이터베이스는 중복을 최소화하고, 서로 관련있는 데이터를 하나로 통합하여 관리하는 데이터.

Stored data:
데이터베이스는 접근할 수 있는 저장장치에 저장된 데이터.

Operational data:
조직의 고유한 기능을 수행하기 위해 필수데이터를 저장한 것.

## 데이터베이스의 특징

Concurrent sharing(동시공용):
여러 사용자가 같은 데이터를 동시에 사용할 수 있음.

Continuous evolution(지속적인 변화):
데이터가 삽입·삭제·수정되면서 계속 변화함

Real-time accessibility: 
사용자가 요구하면 데이터를 즉시 검색·처리할 수 있음

Contents reference(내용에 의한 참조): 
데이터의 위치가 아니라 내용/값으로 데이터를 찾음
예: “학번 20231234인 학생 조회”

Management by DBMS(DBMS에 의한 관리): 
데이터를 응용 프로그램이 직접 관리하지 않고 DBMS가 저장·검색·보안·무결성 등을 관리함

## 데이터베이스 출현 배경
파일:
데이터를 저장하는 가장 기본형식.

파일시스템:
응용프로그램에 필요한 데이터를 파일로 저장하고 관리하는 방식.

### 특징
1. 데이터 종속성(data dependency):
파일 구조가 변경되면 응용프로그램도 변경해야함.

2. 데이터 중복성(data redundancy):
응용프로그램별로 데이터가 독립적이라 데이터 중복이 불가피함.

### 문제점
1. 데이터의 중복 저장으로 효율적인 관리가 어렵다.
2. 데이터의 일관성(consistency)을 유지하기 어렵다.
3. 데이터 무결성(data integrity)을 유지하기 어렵다.
4. 데이터 공유가 어렵다.

## 데이터베이스 장단점

### 장점
1. 데이터 공유가 가능하다.
2. 데이터에 대한 접근을 통제할 수 있다.
3. 중복 데이터가 적어진다.
4. 효율적인 유지보수가 가능하다. 
5. 데이터의 일관성(consistency)을 유지할 수 있다.
6. 생산성 향상
7. 데이터 표준화 가능.

### 단점
1. 초기 개발 비용이 많이 든다.
2. 데이터베이스 관리를 전담할 전문 인력(DB 관리자)이 필요하다.
3. 지속적인 유지보수가 수반되지 않으면 무용지물이 될 수 있다.
