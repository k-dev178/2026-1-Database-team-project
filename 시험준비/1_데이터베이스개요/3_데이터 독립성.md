# 데이터 독립성

## 데이터 독립성?
응용프로그램이 데이터에 종속되지 않음.

## 논리적 데이터 독립성(logical data independency)
\- 응용프로그램에 영향을 주지 않고 개념스키마를 변경할 수 있는것.
\- 외부/개념 매핑에 의해 보장됨.

## 물리적 데이터 독립성(physical data independency)
\- 응용프로그램에 영향을 주지 않고 파일편성과 데이터 액세스 방법을 변경.
\- 개념/내부 매핑에 의해 보장됨.

## system catalog
\- 시스템 테이블.
\- DB에 저장된 객체의 대한 정의나 명세를 수록해서 관리.
\- data dictoinary라고도함

## data directory
\- 시스템 테이블.
\- system catalog의 데이터 참조를 위한 위치정보를 관리.
\- 일반 사용자는 접근 x, 시스템만 사용.
